# My Favorite Series: Bleach

**Bleach** is a *shonen* manga by Tite Kubo, adapted into an anime by Studio Pierrot.

> A teenager gains the powers of a Soul Reaper and protects the living from evil spirits.

---

## My Favorite Character: Ulquiorra
